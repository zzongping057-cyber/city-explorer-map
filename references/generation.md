# 地图生成提示词

用已解析和核实的内容填充下面结构。花括号是编写说明，不得出现在最终提示词中。除用户明确要求外，不把风格编号、色彩编号、图型代码作为画面文字。

```text
风格名称：{选定风格名称}。
参考作者/风格名称：{有实际索引依据时填写}。
视觉语言：{选定风格的正向媒介、线条与色彩特征，不复制场景主体}。
主题色：{主色名称}＋{辅色名称}。
画幅：{期望像素尺寸或宽高比，不写矛盾数值}。

高精细手绘等距轴测地图信息图，鸟瞰视角，微缩城市景观，丰富的建筑与街道细节，鲜艳明亮的色彩，统一的季节氛围，清晰的道路，旅游导览地图风格，精致插画质感，高清细节，海报级视觉效果。根据主题进行信息标注。

主题：{已确认省市、景区名称}，{探索用途}。
编号标注共{实际数量}个：
{逐条列出01至最后一个编号，每条为准确地名及必要的可视辨识特征}。
地理关系：{已核实的主要方位、河流两岸或景区空间关系}。
游览动线：{两条主题线名称、颜色或线型、各自节点顺序}。
图例：{仅包含实际使用的符号及含义}。
地图中的路线为主题游览示意，空间比例允许艺术压缩。
以清楚的中文编号标签呈现地点，长名称换行。标题与主副标签共同参与构图，保证所有编号可读。
```

若节点信息只能支持一条动线，简化路线并在生成前一句说明。未核实的开放状态、票价、通行时间、设施位置不进入提示词。

实际调用和失败交付参见 [出图调用与故障恢复](image-generation.md)。仅提示词模式直接交付正文；出图失败时保留实际发送的完整提示词，不用一份删减版替代原稿。

## 行为复核案例

用于检查决策，不需要每次展示或逐一调用生成工具：

| 输入情况 | 应有决策 |
| --- | --- |
| 只输入“南昌” | 最多10个真实景点，动态选风格，不机械沿用上次画风 |
| 很小的景点，无数量要求 | 少于10个也成立，不凑数扩大成城市地图 |
| “标注15个”与“最多15个” | 前者以15个为目标，后者仅设上限，均覆盖默认10个 |
| 明确给出12个不同景点 | 视为自定义12个，不无声删减 |
| “深圳”后面是全套南昌景点 | 说明以清单为准改为南昌，不混用城市标题 |
| 深圳和广州的多个景点 | 按跨城范围处理，不自动删去另一城市 |
| “FA-021 Hergé”或“C-25 柠檬黄” | 名称优先，说明编号差异，不误用Mari Andrew或橙色 |
| “1792×1024（16:9）” | 请求1792×1024，不同时强制精确16:9；检查实际输出尺寸 |
| 仅提示词 | 不执行图片生成 |
| 无法核实的内部节点 | 不虚构，缩减并说明；地点信息不足才询问必要定位 |
| 提示词交付后用户说“生成图片” | 切换为出图，复用已确认的深圳、10个节点、Hergé、赭石＋克莱因蓝与画幅 |
| 执行单元仍在运行，已返回等待编号 | 等待同一执行单元，不新建图片请求，不把等待返回当成错误 |
| 新图调用被提示不接受某参数 | 依据实际工具契约纠正参数，不擅自添加模型或尺寸字段 |
| 长时间等待后返回无状态码的网络错误 | 说明传输错误、底层原因和结果未知；不自动重发，交付实际提示词文件 |
| 明确暂时性故障且已确认未产出图片 | 按工具建议最多自动重试一次；重试保留用户设计，再失败即停止 |
| 明确鉴权、额度或输入内容错误 | 不按网络故障盲目重试，不自动切换服务或读取密钥 |
| 用户说“修复技能并提交仓库” | 修改并验证技能，不自动重试旧出图任务，不把静态校验说成出图验证 |
| 工具返回图片但没有尺寸元数据 | 检查实际文件尺寸，不照抄提示词中的1792×1024作为结果 |
| 用户说“用Codex图片生成工具，不是ChatGPT网页端” | 直接调用Codex内置工具，该选择覆盖旧版网页备用授权，不操作ChatGPT网页 |
| 当前会话只提供一个Codex图片工具 | 如实说明没有第二个独立备用工具，不把包装、重试或网页端称为另一内置工具 |
| 原工具仍在运行，用户没有要求取消 | 等待原请求，不并行提交第二份生成 |
| Codex工具失败，之前网页已有一张图 | 只报告本次Codex工具结果，不能用旧网页图片冒充本次成功 |
| 用户明确要求重新用Codex生成 | 复用确认方案，提交一次新请求；这属于用户要求的重试，不是引擎切换 |
| 用户允许“生图错误时备用Codex自带工具”，失败入口是另行选择的其他工具 | 保全原结果后，使用完整提示词切换到当前真实可用的Codex内置工具一次，无需重复确认同一次切换 |
| 用户允许Codex备用，但失败入口已经是唯一的 `image_gen.imagegen` | 说明失败的就是Codex内置工具、当前没有独立备用，不把再次调用包装成备用切换 |
