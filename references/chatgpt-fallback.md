# ChatGPT网页备用

在用户明确允许网页备用、且Codex内置出图已失败或不可用时阅读本文件。默认仍先用Codex；用户最新的明确选择决定是否允许网页。只更新技能不自动重发之前的图片任务。

## 进入与提交

1. 保留实际发送的完整提示词及Codex错误，告知“切换到ChatGPT网页版备用”；说明原请求的服务端结果未知（如适用）。同一地点最多提交一次网页备用，不与原工具重试并行。
2. 使用当前可用的浏览器控制工具操作 `https://chatgpt.com/`。优先遵守用户指定的浏览器；已登录的浏览器可直接使用。只浏览当前任务页面，不读取凭据、浏览历史或无关聊天；通过实际页面状态定位控件，不硬编码私有接口、Cookie或内部请求。
3. 若需要登录、验证码或页面要求接管，按当前浏览器工具的规则让用户完成必要步骤；未登录、无权限或没有图片生成能力时如实说明。不要切换账号、购买订阅或安装额外软件。
4. 进入本任务专用聊天，选择页面实际提供的“创建图像”功能（若有），发送同一份完整提示词，保留地点、编号、风格、配色和画幅。页面确实返回输入限制时再处理明确的问题，不静默删减用户要求。
5. 提交后等待该次网页生成，不刷新或反复点击生成。页面明确报错、额度限制或当前自动化无法继续时停止，保留页面状态和错误；仍在生成时按工具允许的观察方式等待，不能把等待误判成失败。

## 原图与交付

- 生成完成后通过页面提供的原图下载操作获取图片；使用浏览器支持的下载或媒体导出能力，不抓取会话凭据或绕过访问限制。
- 将下载的原始图片保存到任务输出目录，文件名含城市与 `chatgpt-web` 并避免覆盖已有结果。记录本次网页聊天URL、输出文件与实际尺寸（能力允许时）。
- 查看原图并按主技能检查城市、节点、文字、布局与真实尺寸。网页截图仅作操作证据，不作为用户请求的成图。
- 可用的本地原图应直接展示并提供路径，明确标注“ChatGPT网页版备用生成”；不要写成Codex内置工具成功，也不要以旧图片充当本次结果。
- 无法下载或导出原图时，提供可访问的本次结果页面并说明原图尚未交付；页面也无结果则交付完整提示词及错误。不得伪报已生成、已保存或网络问题已修复。
- 网页生成失败后不自动切回Codex、不循环创建聊天。同一地点的备用请求完成或失败后即结束该轮；后续重试须有用户请求。

调用与恢复边界见 [出图调用与故障恢复](image-generation.md)，地图内容与检查要求见 [主技能](../SKILL.md)。
