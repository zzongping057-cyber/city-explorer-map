# ChatGPT备用出图

仅在用户已要求或允许使用ChatGPT备用出图时执行。当前会话已有授权则直接继续，不重复询问。没有该授权时先交付失败材料并说明此选项；技能本身不能替用户授权新的外部服务或账号操作。

## 选择真实可用的路径

1. 若客户端实际提供了独立的ChatGPT图片生成工具，阅读并使用它的真实参数。不同名称但指向同一个失败工具的包装不算独立备用，不虚构工具、模型或连接状态。
2. 没有第二个原生工具时，可用已连接的浏览器操作用户已登录的 `https://chatgpt.com/`。这叫“ChatGPT网页端备用”，不能称为新增了一个内置工具，也不能保证与原工具使用不同后端。
3. 只切换到用户选择的ChatGPT路径。第三方生图、单独计费API、CLI、账号切换与代理修改不在此授权范围内。

## 切换与生成

- 等待原工具明确结束或报错后再切换，不能在原请求仍运行时并行重复生成。原结果未知时先检查本次工具提供的恢复入口（若有），告知“原工具已报错，改用ChatGPT备用”；用户已经允许备用，无须重新批准同一操作。
- 登录、额度或内容限制不能通过备用入口绕过。遇到这些明确限制时，按对应错误处理。
- 网页端先确认登录状态和可用的“创建图像 / Create image”入口；浏览器或会话尚在加载不代表未登录。遇到用户必须完成的登录或验证时保留页面并说明实际阻塞；不读取浏览器凭据或Cookie。
- 新建本任务专用的普通聊天，或继续本任务已经创建的聊天，不把提示词发进无关聊天。通过页面可见的图片入口选择出图，粘贴已保全的完整提示词并提交一次；工具标签可能由界面自动添加，不改动原有地点、编号、风格配色和画幅。
- 提交后记录本任务聊天URL（可用时）和可见状态。页面显示“正在生成”就等待原聊天；不要刷新、反复点击发送或重新建聊来代替等待。等待期间可继续与出图无关的技能验证工作。
- 网页弹出明确失败或限制时停止该路径，保存错误摘要；本次备用最多发起一次初始生成，不再在内置与网页入口间循环。成图质量修正仍按主技能的一次聚焦修正规则处理。

## 取得与交付

- 只有可见的实际生成图片才算出图成功；提示词回显、工具占位、加载动画或网页截图不能冒充原图。
- 优先通过页面的“下载 / 保存图片”控件取得原图，核对实际文件尺寸、10个或用户指定数量的编号、地名和画风。下载名称不可预测时使用浏览器返回的真实文件路径，再另存到本任务输出目录，不覆盖已有版本。
- 下载控件没有可捕获的下载事件或浏览器不支持Blob下载时，先检查是否存在保存对话框或本次下载结果，避免重复下载。可使用页面“复制图像”后读取该次复制产生的PNG剪贴板数据，原样保存并检查实际尺寸；复制可能异步完成，首次读空时先核对页面状态，再读取一次。不得读取与本任务无关的原有剪贴板内容，也不把截图当作复制的原图。
- 不通过抓取Cookie、私有接口或账号令牌下载图片。截图可作预览或执行证据，需标明截图，不能把截图尺寸当作原图尺寸。
- 能取得原图时内联展示并提供文件；只能在网页查看时给出本任务聊天链接并说明原图下载受限；生成失败则交付保全提示词及两个路径各自的错误，不声称成功。
- 生成成功只能证明本次备用路径可用，不证明原工具网络故障已修复。聊天URL、账号信息和私人截图不随技能源码提交到公共仓库。
