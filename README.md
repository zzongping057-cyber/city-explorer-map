# 城市景点探索地图 · city-explorer-map

输入城市、景区或景点名称，自动选点、匹配画风并生成等距轴测探索地图。

当前版本：**1.0.2**。在故障分类、提示词保全与有限重试基础上，增加用户允许的ChatGPT备用出图路径；不代表原图片工具的网络问题已修复。

## 功能

- 默认最多10个编号标注，支持自定义6个、15个等数量。
- 根据地域特色、受众、主题与信息密度，从366条画风和36条配色文本索引中动态选择。
- 默认采用IG-037等距轴测地图构图，配有主题游览双动线和图例。
- 核实地名、合并别名，检查城市与景点清单是否一致。
- 支持自定义主题、画风、配色、尺寸，或仅输出提示词。
- 生成后核对标签与实际文件尺寸，不将提示词尺寸当成实际输出尺寸。
- “仅提示词”之后可直接说“生成图片”，继续使用已确认方案。
- 出图失败时保留完整提示词并提供可复用文件；未知结果的长时间网络错误不会盲目自动重发。
- 用户允许ChatGPT备用后，可在内置工具失败时切换到独立可用工具或已登录的ChatGPT网页“创建图像”，复用同一方案。

## 安装到 Codex

将本仓库地址发给 Codex，要求安装此技能；也可以将仓库复制到用户技能目录中的 `city-explorer-map` 文件夹，确保该文件夹直接包含 `SKILL.md`。

## 使用

```text
使用 $city-explorer-map 南昌
使用 $city-explorer-map 滕王阁，最多6个标注，亲子探索
使用 $city-explorer-map 杭州，标注15个，文化漫游
使用 $city-explorer-map 深圳，Hergé 欧洲清晰线画，赭石+克莱因蓝，仅提示词
使用 $city-explorer-map 深圳，内置工具失败时使用ChatGPT备用出图
```

只输入地点名称即可使用，其余参数自动选择。用户明确指定的风格、配色和数量优先。

## 文件

- `SKILL.md`：技能入口与流程。
- `agents/openai.yaml`：Codex技能显示名称及默认调用示例。
- `references/styles.json`：366条画风文本索引。
- `references/colors.json`：36条配色文本索引。
- `references/generation.md`：提示词结构与行为复核案例。
- `references/image-generation.md`：工具调用、故障分类、重试停止条件与失败交付。
- `references/chatgpt-fallback.md`：用户允许的ChatGPT备用路径、网页生成与原图交付。

## 运行条件与说明

需要支持技能的客户端，以及可用的图片生成与联网检索工具；本仓库不包含模型、密钥或原库参考图片。地图路线是主题游览示意，允许艺术压缩，不用于实时导航。

默认期望尺寸为1792×1024，实际比例为7:4；精确尺寸能否实现取决于生成工具，交付时应报告真实尺寸。若只指定16:9，则使用工具支持的16:9尺寸。

技能格式、索引唯一性、本地引用与界面元数据可在本地校验。行为复核案例见 `references/generation.md`；静态校验不等于出图成功，尚未对所有地点进行实际出图测试。

### 出图失败时

`image generation failed: network error: error sending request` 表示本次工具报告了网络错误；若没有更详细的信息，不能确定是连接、代理、超时还是服务端问题，也不能据此认定画风或提示词有问题。

先核对本次工具是否有可恢复结果，再保存实际发送的完整提示词与简短错误摘要。长时间等待后结果未知时停止自动重发；明确可安全重试的暂时故障最多自动重试一次。鉴权、额度和内容输入问题分别处理，不通过反复调用解决。

本技能不修改系统代理、不读取账号凭据，也不自动改用第三方或单独计费API。具体规则见 [出图调用与故障恢复](references/image-generation.md)。

### ChatGPT备用

明确说“失败时用ChatGPT备用”即可允许此路径；同一会话无需重复确认。客户端没有第二个图片工具时，通过已登录的 `chatgpt.com` 网页“创建图像”提交一次，等待同一聊天完成，并通过页面下载控件取得原图。网页路径不等于新增了独立后端，也不保证原工具恢复。登录、额度或内容限制不能通过备用绕过。详见 [ChatGPT备用出图](references/chatgpt-fallback.md)。

2026-10-25已在本机实际验证网页创建图像及PNG导出；原内置工具是否恢复仍未验证。下载事件不可捕获时，可用页面“复制图像”取得本次生成的PNG，不能用截图冒充原图。
